# AgroGest-SCM

Projeto acadêmico de gerenciamento de configuração de software utilizando Git e GitHub.



\## Objetivo do projeto



O AgroGest é um projeto acadêmico fictício voltado à organização de informações de propriedades rurais.



Nesta atividade da Unidade 4, o repositório será utilizado para praticar o gerenciamento de configuração de software, incluindo o controle de versões, a modificação de arquivos e a sincronização entre o computador e o GitHub.



\## Funcionalidades previstas



\- Cadastro de propriedades rurais.

\- Registro da produção agrícola.

\- Controle de despesas.

\- Gerenciamento de usuários.



\## Ferramentas utilizadas



\- Git: controle de versões dos arquivos.

\- GitHub: armazenamento remoto e histórico das alterações.
